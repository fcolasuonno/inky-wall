{{ card_head('How it works', icon_name='question', level=2, collapse='gbp-how') }}
  1. The plugin pins one photo in the gallery cell using the widget's file option (its own sequential cursor is bypassed).
  2. Tesserae renders and pushes the page; the panel paints it on wake.
  3. The next heartbeat reports paint_seq and painted_digest.
  4. The plugin checks the event log: if that digest came from a push of this gallery page, the photo was consumed and the pin moves to the next one.

Button wakes that find no new frame don't increment paint_seq, so they cost no lineup steps. Pushes from the Send tab or another dashboard don't match the gallery page and are ignored. Requires firmware inky13-tesserae-0.2 or later.
