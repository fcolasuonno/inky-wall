{{ card_head('How it works', icon_name='question', level=2, collapse='gbp-how') }}
  1. The plugin pushes the next gallery image directly with push_image() — the same path as Send → File — so no Chromium render is involved.
  2. The panel paints it on wake and reports paint_seq and painted_digest in its next heartbeat.
  3. The plugin checks the event log: if that digest came from its own direct push, the photo was really displayed and the next one is pushed immediately.

Every wake — timer or button — pushes the next image. The gallery deck must be disabled so scheduled page renders cannot overwrite these frames. Requires firmware inky13-tesserae-0.3 or paperless-L-tesserae.
