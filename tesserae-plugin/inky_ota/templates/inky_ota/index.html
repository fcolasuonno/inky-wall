Inky13 OTA trigger

Publishes a one-shot retained command to {{ topic }}. After enabling, press the panel button: the firmware wakes, clears the command, and opens an ArduinoOTA window for a few minutes. Upload with pio run -e tesserae-ota -t upload.

Where to configure

Settings → Plugins → Inky13 OTA trigger lets you change the device id and command token. The token must match OTA_CMD_TOKEN in the firmware's tesserae_config.h.
